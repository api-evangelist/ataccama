# Ataccama ONE Documentation

> Technical reference for Ataccama ONE — a unified platform for Data Quality, Data Catalog, Data Observability, Data Lineage, Master Data Management, and Reference Data Management. Current release: v17.0.0. Use `/latest/` paths for the most recent stable version.

Documentation is organized by module. Each module has its own versioned docs under
docs.ataccama.com. The platform is available as Ataccama Cloud (fully managed SaaS)
or hybrid deployment (data processed locally, platform in cloud).

Important notes for developers:
- API authentication uses JWT tokens — see API Requests Authentication before making calls
- Data Quality rules use the ONE Expressions language — see the Expressions Reference
- Generative AI features operate exclusively on metadata, never on raw data values
- Hybrid DPE (Data Processing Engine) runs in the customer's environment; only metadata
  is sent to the cloud

## Product Modules

- [Ataccama ONE Agentic](https://docs.ataccama.com/ataccama-one-agentic/latest/overview.html): Agentic AI layer — autonomous data stewardship, rule generation, and anomaly resolution.
- [ONE DQ&C (Data Quality & Catalog)](https://docs.ataccama.com/one/latest/overview.html): Core module for data quality, catalog, observability, lineage, and ONE Data. Current version: v17.0.0.

- [ONE Desktop](https://docs.ataccama.com/one-desktop/latest/overview.html): Desktop client for authoring DQ rules, transformation plans, and local data processing.
- [ONE Runtime Server](https://docs.ataccama.com/runtime-server/latest/one-runtime-server.html): Runtime server for on-premise and hybrid deployments.
